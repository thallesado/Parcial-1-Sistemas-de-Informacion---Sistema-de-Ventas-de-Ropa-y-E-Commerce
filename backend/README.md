# Backend

Esta carpeta conserva la estructura acordada para el backend. Durante la etapa
de modelado no contiene API, persistencia ni procesos de negocio.

```text
backend/
├── src/
│   ├── config/
│   ├── controllers/
│   ├── middlewares/
│   ├── models/
│   ├── repositories/
│   ├── routes/
│   ├── services/
│   └── utils/
└── tests/
```

Las carpetas se mantienen mediante archivos `.gitkeep` hasta iniciar la API.
